# robertcgregory.com

Personal site for Rob Gregory. Static Next.js (App Router) on Vercel.

- Identity is independent of Business Rocket, Pavilion, AuraFlux, and HSKRG Staff apps.
- Brand assets in `/public`: crest, favicon, OG, and Gmail signature URLs
  (`/logo-email.png`, `/logo-signature.png`).

```bash
npm install
npm run build
```

Deploy: Vercel project `robertcgregory` on `robert-4220s-projects`.
